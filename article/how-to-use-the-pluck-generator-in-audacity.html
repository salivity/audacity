How to Use the Pluck Generator in Audacity

Audacity includes a built-in synthesis tool called Pluck that produces realistic plucked string tones using the Karplus-Strong physical modeling algorithm. This guide provides a straightforward walkthrough on how to locate the Pluck generator, configure its pitch and decay settings, and render custom synthesized string notes directly into your audio timeline.

Step 1: Set Up an Audio Track

  1. Launch Audacity.
  2. Go to the top menu and select Tracks > Add New > Mono Track (or Stereo Track depending on your project needs).
  3. Click on the track timeline where you want the note to begin, or highlight an area if you have a predefined duration in mind.

Step 2: Open the Pluck Generator

  1. Click on the Generate menu at the top of the screen.
  2. Select Pluck... from the dropdown list. A configuration window will appear with parameters for pitch, decay, and duration.

Step 3: Configure the Note Parameters

  • MIDI Pitch No. (32 to 96): Enter the MIDI note number for the pitch you want to create. For reference, standard MIDI note 60 corresponds to Middle C (C4), 69 corresponds to Concert A (A440), and 40 corresponds to the low E on a standard acoustic guitar.
  • Fade-out type: Choose how the note naturally decays.
    • Abrupt: Simulates muting or damping the string quickly after it is plucked.
    • Gradual: Allows the string vibration to decay naturally, creating a resonant acoustic sustain.
  • Duration: Set the total length of the audio clip using hours, minutes, seconds, or milliseconds. Ensure this value provides enough time for the note to decay naturally if using a gradual fade.

Step 4: Generate the Note

  1. Click the Generate (or OK) button to insert the synthesized waveform into your track.
  2. Press the Spacebar to listen to the result.

Creating Melodies and Chords

To compose simple chord progressions or melodies using Pluck:

  • For Melodies: Place the cursor immediately after your first generated note, reopen the Pluck generator, input a new MIDI pitch, and generate the next note in sequence.
  • For Chords: Create multiple audio tracks, line up the cursor at the identical timestamp across each track, and generate harmonic intervals (such as root, third, and fifth MIDI pitches) across the separate tracks.
