How to Record a Backup Track in Audacity

Setting up a secondary backup recording track simultaneously in Audacity prevents audio loss from unexpected clipping, distortion, or system hiccups. Because Audacity natively records from only one audio device at a time, creating a simultaneous backup track—often called a "safety track"—requires configuring a multi-channel input or utilizing virtual audio routing. This guide explains how to set up hardware splitting for a lower-gain safety track and how to use software routing to capture simultaneous backup audio in Audacity.

Method 1: Creating a Lower-Gain Safety Track (Recommended)

The most common reason to record a secondary simultaneous track is to keep an identical backup at a lower volume (around -10 dB to -12 dB) to salvage audio if your primary track peaks and distorts.

1. Configure Your Hardware

  • With an Audio Interface/Mixer: Plug your microphone into Input 1. Use an interface feature (such as a hardware split or loop) or an XLR Y-splitter cable to send the same microphone signal into Input 2.
  • Set Independent Gain Levels: Set the gain on Input 1 for standard levels (peaking around -6 dB to -3 dB). Set the gain on Input 2 significantly lower (peaking around -15 dB to -12 dB).

2. Configure Audacity

  1. Open Audacity.
  2. Click on the Audio Setup button in the top toolbar.
  3. Set Recording Device to your multi-channel audio interface.
  4. Set Recording Channels to 2 (Stereo) Recording Channels.
    • Input 1 will record to the Left channel.
    • Input 2 will record to the Right channel.

3. Separate the Tracks After Recording

  1. Click the Record button. Audacity will record both inputs simultaneously on a single stereo track.
  2. Once finished, click the drop-down arrow next to the track name on the track control panel.
  3. Select Split Stereo to Mono.
  4. You now have two independent mono tracks: your primary vocal track and your secondary, lower-volume backup track.

Method 2: Software Routing for Multiple Devices

If your backup requires capturing a completely different input device (such as a secondary USB microphone or internal computer audio) at the exact same time, you must combine the devices into a single virtual interface before opening Audacity.

On Windows (Using VoiceMeeter)

  1. Download and install a virtual audio mixer like VB-Audio VoiceMeeter.
  2. Open VoiceMeeter and set Hardware Input 1 to your primary microphone.
  3. Set Hardware Input 2 to your secondary backup microphone.
  4. Route both inputs to the virtual output (B1).
  5. Open Audacity, navigate to Audio Setup, and set the Recording Device to VoiceMeeter Output.
  6. Set Recording Channels to 2 (Stereo). Input 1 will route to the left channel, and Input 2 will route to the right.

On macOS (Using Aggregate Device)

  1. Open Audio MIDI Setup (found in Applications > Utilities).
  2. Click the + icon in the bottom-left corner and select Create Aggregate Device.
  3. Check the boxes next to both your primary audio device and your secondary backup device.
  4. Open Audacity, select Audio Setup, and choose your new Aggregate Device as the recording device.
  5. Set the channels to match the total inputs assigned in Audio MIDI Setup (e.g., 2 or more channels).
  6. Press Record to capture both streams simultaneously onto parallel channels.
