Save Audacity Projects to Cloud via audio.com

This guide provides a straightforward walkthrough on saving your Audacity projects directly to the cloud using the native audio.com integration. Introduced in modern versions of Audacity, cloud saving allows you to back up your audio files securely, work across multiple devices, and easily share your recordings with others without manually exporting or moving large project files.

Prerequisites

  • Audacity 3.5 or newer: Cloud project saving is natively integrated starting with Audacity version 3.5.
  • An audio.com account: You will need an active audio.com account to store your projects. You can create one for free during the linking process.

Step 1: Link Audacity to Your audio.com Account

  1. Open Audacity.
  2. Look at the top-right corner of the interface and click the Cloud icon or click the audio.com button. Alternatively, go to File > Save Project > Save to Cloud.
  3. A prompt will appear asking you to sign in. Click Link Account.
  4. Your default web browser will open to the audio.com authorization page.
  5. Sign in to your audio.com account (or create a new one) and click Authorize.
  6. Once authorized, a confirmation message will appear, and Audacity will automatically update to show your account is linked.

Step 2: Save Your Project to the Cloud

  1. With your audio project open and ready in Audacity, go to the top menu bar.
  2. Navigate to File > Save Project > Save to Cloud.
  3. A dialog box will appear allowing you to:
    • Name your project: Enter a title for the audio file.
    • Set privacy settings: Choose whether the project should be Private (only visible to you), Unlisted (accessible to anyone with the link), or Public (searchable on audio.com).
  4. Click Save.
  5. Audacity will upload your project data directly to your audio.com cloud storage. The upload progress will be displayed at the bottom of the workspace.

Step 3: Open an Existing Cloud Project

  1. Launch Audacity.
  2. Navigate to File > Open.
  3. On the left-hand navigation pane of the file browser, select the Cloud Projects tab (or choose the cloud tab directly from the Audacity welcome screen).
  4. Select the project you wish to open and click Open.
  5. Audacity will sync and download the necessary audio data, allowing you to edit seamlessly from anywhere.
