Audacity 64-Bit Supported Operating Systems

Modern releases of Audacity (version 3.0 and newer) offer native 64-bit architecture support across the major desktop platforms. This article outlines the specific 64-bit operating systems officially supported by current versions of Audacity, including system requirements for Microsoft Windows, Apple macOS, and Linux distributions.

Microsoft Windows

Modern 64-bit builds of Audacity officially support:

  • Windows 11 (64-bit)
  • Windows 10 (64-bit)

Older 64-bit Windows releases, such as Windows 7, Windows 8, and Windows 8.1, are no longer officially supported by the Audacity development team. While older versions of the operating system may run the application, compatibility updates, security fixes, and technical support are strictly limited to Windows 10 and 11.

Apple macOS

Audacity provides 64-bit universal binaries compatible with both Intel-based Macs and Apple Silicon (M1, M2, M3, and newer chips). Officially supported versions include:

  • macOS 15 (Sequoia)
  • macOS 14 (Sonoma)
  • macOS 13 (Ventura)
  • macOS 12 (Monterey)
  • macOS 11 (Big Sur)
  • macOS 10.15 (Catalina)
  • macOS 10.14 (Mojave)
  • macOS 10.13 (High Sierra)

Modern Audacity releases run natively on Apple Silicon without requiring the Rosetta 2 translation layer.

Linux

Audacity is officially supported on 64-bit Linux operating systems through portable containerized formats. Supported distributions generally include modern releases of:

  • Ubuntu (64-bit)
  • Debian (64-bit)
  • Fedora (64-bit)
  • Arch Linux (64-bit)
  • openSUSE (64-bit)

The primary official method of distribution for Linux is a 64-bit AppImage, which requires a system with glibc version 2.31 or newer. Audacity is also officially maintained and distributed as a 64-bit Flatpak via Flathub.
