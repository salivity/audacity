Using Parametric EQ VST Plugins in Audacity

Audacity fully supports third-party parametric equalizer VST plugins, allowing users to perform precise, real-time frequency shaping beyond the capabilities of the native equalization tools. Modern versions of Audacity support both VST2 and VST3 formats on Windows, macOS, and Linux. This article outlines plugin compatibility requirements, the step-by-step process for installing and activating a third-party parametric equalizer, and how to use non-destructive, real-time processing within your audio projects.

Plugin Compatibility Requirements

Before installing a third-party parametric EQ, ensure the plugin matches your Audacity installation architecture:

  • Bit Architecture: If you run a 64-bit version of Audacity (standard for recent releases), you must install 64-bit VST plugins. A 32-bit plugin will not be recognized by a 64-bit Audacity host.
  • Plugin Formats: Audacity supports VST2 (.dll on Windows, .vst on macOS) and VST3 (.vst3) formats. VST3 is recommended for better performance and native support for real-time adjustments.

How to Install and Enable a Parametric EQ

  1. Install the Plugin: Run the installer provided by the plugin manufacturer. Most VST3 plugins automatically install into the standard system directory (C:\Program Files\Common Files\VST3 on Windows, /Library/Audio/Plug-Ins/VST3 on macOS).
  2. Rescan Plugins in Audacity: Open Audacity and navigate to Effect > Plugin Manager.
  3. Locate the EQ: Find your new equalizer in the list. If it does not appear, click Rescan to detect newly added files.
  4. Enable the Plugin: Select the equalizer, click Enable, and click OK.

Using Real-Time Parametric Equalization

Starting with Audacity 3.2, non-destructive real-time effects are natively supported, which is essential for adjusting parametric EQ bands while listening to playback:

  1. Import or record your audio track.
  2. Click the Effects button located on the track control panel on the left side of the track.
  3. Click Add Effect in the Realtime Effects sidebar.
  4. Select your third-party parametric EQ from the list.
  5. Click the plugin name to open its graphical interface. You can now tweak frequency, Q (bandwidth), and gain nodes in real time during playback.

Applying Destructive Processing (Alternative)

If you prefer to render the equalization permanently into the waveform:

  1. Highlight the section of audio you wish to process.
  2. Go to the top menu and select Effect.
  3. Locate your third-party equalizer under its designated category or manufacturer folder.
  4. Adjust your parameters in the plugin window, preview the audio, and click Apply.

Common Free Parametric EQ Options

If you need a capable third-party parametric EQ to get started, the following options are fully compatible with Audacity:

  • Tokyo Dawn Records (TDR) Nova: A powerful dynamic parametric equalizer offering standard EQ control alongside multi-band compression features.
  • Voxengo PrimeEQ: A straightforward, user-friendly parametric equalizer optimized for clean tonal balance.
  • Cockos ReaEQ: Part of the ReaPlugs suite, this is a lightweight, unlimited-band parametric EQ ideal for high efficiency and low CPU usage.
