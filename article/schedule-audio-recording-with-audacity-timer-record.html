Schedule Audio Recording with Audacity Timer Record

Audacity includes a built-in Timer Record feature that allows you to automate audio capture without being present at your computer. This guide details how to configure your recording devices, set precise start and end times, and define automated post-recording actions such as saving projects or shutting down your system.

Step 1: Set Up and Test Your Audio Input

Before scheduling the recording, ensure your input device is active and configured correctly:

  1. Connect your microphone, interface, or enable internal recording (such as "Stereo Mix" on Windows or a loopback device on macOS).
  2. Open Audacity and locate the Audio Setup toolbar.
  3. Select your intended Host, Recording Device, and Recording Channels (Mono or Stereo).
  4. Perform a quick manual test recording to confirm input levels are balanced and not clipping. Delete the test track before proceeding.

Step 2: Open the Timer Record Window

Open the scheduler interface using either method:

  • Press the keyboard shortcut Shift + T.
  • Go to the top menu and select Transport > Recording > Timer Record...

Step 3: Set the Recording Schedule

The Timer Record dialog box provides fields to define when recording occurs:

  • Start Date and Time: Set the exact date, hour, minute, and second you want the recording to begin. If you want it to begin immediately, leave the start time as the current time.
  • End Date and Time: Specify when the recording should conclude.
  • Duration: Alternatively, adjust the duration fields (hours, minutes, seconds). Modifying the duration automatically adjusts the "End Date and Time" field, and vice versa.

Step 4: Configure Automatic Save and Export Actions

Beneath the scheduling fields, Audacity allows you to specify what happens once the recording completes:

  • Save project as: Automatically saves the recording as an Audacity project file (.aup3) to a chosen folder.
  • Export audio: Automatically exports the file directly to standard formats like WAV or MP3. Click the options button next to it to select the destination folder, file format, and sample rate.

Step 5: Configure Post-Recording System Actions

You can instruct Audacity to manage system power states when the session concludes:

  • Choose Do nothing to leave Audacity open.
  • Choose Close Audacity to quit the application after saving.
  • Choose Restart system or Shut down system if you are running an overnight or unattended capture and want to conserve power.

Step 6: Arm the Timer

  1. Click the OK button at the bottom of the window.
  2. A progress window will appear displaying the countdown to the start time, remaining recording time, and scheduled actions.
  3. Keep the computer powered on and leave Audacity running. Ensure that your operating system's sleep or hibernation settings are disabled for the scheduled period to prevent the machine from suspending operation before recording begins.
