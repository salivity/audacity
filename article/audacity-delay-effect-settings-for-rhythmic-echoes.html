Audacity Delay Effect Settings for Rhythmic Echoes

Audacity’s built-in Delay effect allows users to craft synchronized, tempo-matched echo patterns to enhance music, podcasts, and sound design. This guide details every parameter available in the Delay effect and explains how to configure each setting to produce clean, rhythmic repeats aligned with a project's tempo.

Delay Type

The Delay type dropdown dictates how repeats behave over time. It offers three options:

  • Regular: Produces echoes spaced at identical time intervals. This is the essential setting for standard rhythmic echoes that lock into a musical tempo.
  • Bouncing Ball: Progressively shortens the interval between echoes, mimicking a bouncing ball coming to rest.
  • Reverse Bouncing Ball: Starts with rapid echoes that gradually space farther apart.

For musical and strictly rhythmic patterns, keep this set to Regular.

Delay Level per Bounce (dB)

This slider controls the volume drop of each successive echo, functioning identically to a feedback or decay control:

  • Negative values (e.g., -3 dB to -6 dB): Each repeat is quieter than the last, allowing the echo to fade naturally into the mix.
  • 0 dB: Each repeat remains at the same volume as the original sound, creating an infinite-style loop for the duration of the set bounces.
  • Positive values: Each echo becomes louder than the previous one, which can quickly cause clipping and distortion.

For a balanced rhythmic trail, settings between -3 dB and -6 dB provide a natural decay without cluttering the track.

Delay Time (seconds)

Delay time controls the precise duration between each echo. To make an echo rhythmic, this value must match the beats per minute (BPM) of the audio:

  • Quarter Note (1 beat): 60 / BPM (e.g., at 120 BPM: 60 / 120 = 0.50 seconds).
  • Eighth Note (1/2 beat): 30 / BPM (e.g., at 120 BPM: 30 / 120 = 0.25 seconds).
  • Dotted Eighth Note: 45 / BPM (e.g., at 120 BPM: 45 / 120 = 0.375 seconds).

Entering the exact calculated decimal into this field synchronizes the echoes perfectly to the track's grid.

Pitch Change Effect

This setting determines if and how the repeats change in pitch:

  • Pitch change: Adjusts the pitch of each successive echo up or down.
  • Pitch and tempo change: Alters both the pitch and the playback speed of each echo.
  • None: Maintains the original pitch across all repeats.

Select None to ensure musical echoes remain in key and maintain their rhythmic spacing.

Pitch Change per Bounce (semitones)

When a pitch effect is enabled, this slider sets the interval shift (in semitones) for each repeat. For standard rhythmic echoes, leave this slider at 0 so repeats do not shift away from the root note of the track.

Number of Bounces

This parameter defines the total count of echoes generated after the initial sound:

  • Lower values (2 to 4) create subtle, tight rhythmic accents.
  • Higher values (8 to 16+) produce sustained rhythmic trails.

To ensure the echoes stop on a specific musical measure, multiply the number of bounces by the note value chosen in the Delay time setting.
