Select All Tracks in Audacity Keyboard Shortcut

Selecting every audio track in Audacity at once is an essential skill for speeding up your editing workflow, applying global effects, or exporting entire projects. This guide covers the primary keyboard commands used to select all audio tracks simultaneously across Windows, macOS, and Linux, as well as commands for selecting all tracks within a specific time region.

The Universal Shortcut to Select All

To select every audio track and all audio data across the entire project timeline:

  • Windows and Linux: Press Ctrl + A
  • macOS: Press Cmd + A

Once pressed, the background of all audio tracks will change color (typically turning light blue or gray, depending on your theme), indicating that every track and its contents are fully selected.

Select All Tracks Within a Specific Time Range

If you have already highlighted a specific time region and want to extend that exact selection across every track in the project without selecting the entire timeline:

  • Windows and Linux: Press Ctrl + Shift + K
  • macOS: Press Cmd + Shift + K

This command toggles the selection across all audio tracks vertically while preserving your horizontal start and end points.

Keyboard Navigation for Selecting Multiple Tracks

If you prefer navigating tracks individually using only your keyboard:

  1. Use the Up Arrow and Down Arrow keys to move the track focus border between tracks.
  2. Press Enter (or Return on macOS) to toggle the selection state of the currently focused track.
  3. Hold Shift and press the Up Arrow or Down Arrow to extend your track selection up or down sequentially.
