How to Export Multiple Tracks in Audacity

Exporting multiple tracks as separate audio files in Audacity is a fast, automated process that eliminates the need to manually solo and save each track one by one. By utilizing the built-in "Export Multiple" feature, you can take a multi-track project and render every track into its own distinct file—such as MP3, WAV, or FLAC—in a single batch. This guide covers how to prepare your project, configure export settings, and output all individual files at once.

1. Name Your Tracks

Audacity uses track titles as the default filenames during batch export.

  • Click the track name located in the track control panel on the left side of each audio waveform.
  • Select Name... or simply double-click the track name.
  • Enter the desired name for each individual file.

2. Open the Export Multiple Dialog

Depending on your version of Audacity, the menu navigation varies slightly:

  • Audacity 3.4 and newer: Go to File > Export Audio..., then set the Export Range option to Multiple Files.
  • Audacity 3.3 and older: Go to File > Export > Export Multiple... (or press the keyboard shortcut Ctrl + Shift + L on Windows/Linux, or Cmd + Shift + L on Mac).

3. Configure Your File and Split Settings

In the export window, adjust the following parameters to ensure your files render correctly:

  • Folder / Export Location: Click Browse to choose the destination directory where your separate audio files will be saved.
  • Format: Select your preferred audio format (e.g., WAV (Microsoft), MP3, or Ogg Vorbis) and configure quality settings (e.g., bit rate or sample rate).
  • Split Files Based On: Select the Tracks radio button. This tells Audacity to render each horizontal track into its own standalone file rather than splitting by labels.
  • Name Files: Choose Using Track Name so the exported files inherit the labels you assigned in Step 1. Alternatively, you can select Numbering after File name prefix to add sequential numbers.

4. Execute the Batch Export

  • Click the Export button.
  • If your tracks do not already contain metadata, Audacity may display the Edit Metadata Tags window for each file sequentially. Click OK through each prompt, or click Don't show this when exporting in Audacity's preferences to skip this step.
  • A progress bar will appear as the audio renders.

Once processing finishes, an Export Summary dialog will appear listing all the successfully generated files and their save directory. Click OK to complete the process.
