Can You Play VSTi Plugins in Audacity?

Audacity does not support playing virtual instrument plugins (VSTi) or triggering MIDI synthesizers in real time. Although recent updates have introduced real-time processing for audio effects and basic MIDI playback capabilities, Audacity remains an audio editor rather than a full digital audio workstation (DAW), meaning you cannot load a software instrument and play it directly using a MIDI keyboard.

VST Effects vs. VST Instruments (VSTi)

Audacity differentiates between audio effect plugins and instrument plugins:

  • Audio Effects (VST / VST3): Audacity fully supports real-time adjustments for effects like equalizers, reverbs, delays, and compressors. These plugins process existing audio signals directly on a track.
  • Instrument Plugins (VSTi): Audacity cannot host or run virtual instruments (such as software synthesizers, sampled pianos, or drum machines). It lacks the internal MIDI-to-audio routing engine required to convert incoming MIDI notes into sound via a plugin.

Audacity’s Current MIDI Capabilities

While you cannot play instruments in real time, Audacity does offer limited MIDI functionality:

  • Import and Export: You can import and display standard MIDI files (.mid) on Note Tracks.
  • Playback: Audacity can send MIDI data to an external synthesizer or your operating system’s default software synthesizer (such as the Microsoft GS Wavetable Synth on Windows) for basic playback.
  • Editing: You can perform minor edits on MIDI note tracks, but you cannot assign custom VSTi plugins to shape the sound.

Recommended Alternatives for Real-Time Playing

If you need to play software synthesizers or VST instruments in real time with a MIDI controller, consider using a dedicated DAW. Programs such as Reaper, Cakewalk by BandLab, Tracktion Waveform Free, or GarageBand offer native support for VSTi hosting with low-latency real-time performance.

Alternatively, if you must use Audacity for recording, you can run a software synthesizer as a standalone application outside of Audacity, select your computer's stereo mix or a virtual audio cable as Audacity's recording input, and record the generated audio directly onto an audio track.
