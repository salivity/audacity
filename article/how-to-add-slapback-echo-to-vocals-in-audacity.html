How to Add Slapback Echo to Vocals in Audacity

Slapback echo is a classic vocal production technique characterized by a single, fast repetition that adds depth, thickness, and vintage character to a recording without muddying the mix. Originating in 1950s rockabilly and surf rock, this effect remains widely used across modern rock, pop, and indie genres. This guide explains how to dial in an authentic slapback delay on your vocal track using Audacity's built-in tools.

Method 1: Using the Built-in Echo Effect

The quickest way to apply a slapback echo is with Audacity’s native Echo effect.

  1. Select the Audio: Click and drag to highlight the vocal track or section you want to process, or double-click the track to select the entire clip.
  2. Open the Echo Tool: Navigate to the top menu and select Effect > Delay and Reverb > Echo.
  3. Set the Delay Time: Slapback requires a short delay between 70 and 150 milliseconds. In the Delay time (seconds) box, enter a value between 0.07 and 0.14. A value of 0.10 (100 ms) is standard for classic slapback.
  4. Set the Decay Factor: Enter a value between 0.3 and 0.5 in the Decay factor box. A lower decay factor ensures that only one prominent echo is heard before the signal disappears, which is the defining characteristic of slapback.
  5. Preview and Apply: Click the Preview button to audition the effect. Adjust the delay time if the repeat feels too fast or too slow, then click Apply.

Method 2: The Duplicate Track Method (For Greater Control)

For greater control over volume, panning, and tonal shaping of the echo, use a separate duplicate track.

  1. Duplicate the Vocal: Select your vocal track and press Ctrl + D (Windows) or Cmd + D (Mac) to create a copy on a new track below the original.
  2. Rename the Tracks: Label the top track "Vocal Dry" and the bottom track "Vocal Slap."
  3. Shift the Timing:
    • Select the Clip boundaries or use the Time Shift functionality.
    • Zoom in closely on the waveform.
    • Shift the duplicate track slightly to the right by approximately 70 to 120 milliseconds. Alternatively, place the cursor at the start of the duplicate track and insert a brief silence via Generate > Silence set to 0.1 seconds.
  4. Adjust Track Levels: Pull the volume slider on the "Vocal Slap" track down to between -6 dB and -12 dB so the echo sits naturally beneath the lead vocal rather than competing with it.
  5. Shape with EQ (Optional): Vintage slapback was produced using analog tape machines that rolled off extreme frequencies. Select the duplicate track, open Effect > EQ and Filters > Filter Curve EQ, and apply a high-pass filter around 150 Hz and a low-pass filter around 5 kHz to mimic authentic vintage tape echo.
