How to Export Audio by Labels in Audacity

Audacity allows you to automatically export individual audio segments based on defined label boundaries using its built-in "Export Multiple" function. By placing region labels around specific sections of your waveform, you can split a single audio track into multiple distinct files in one automated batch process. This guide explains how region labels work and provides straightforward steps to configure and export your audio segments efficiently.

Understanding Region Labels

In Audacity, labels come in two forms: point labels and region labels. While a point label marks a single instant in time, a region label spans a duration with a distinct start and end point. When you use region labels, Audacity recognizes the boundaries of each labeled area as an individual track, allowing you to export only the highlighted segments while ignoring any unlabeled gaps between them.

Step-by-Step: Exporting Audio by Labels

  1. Create Region Labels:
    • Select the portion of audio you want to isolate using the Selection Tool.
    • Press Ctrl + B (Windows) or Cmd + B (Mac), or go to Edit > Labels > Add Label at Selection.
    • Type a name for the label. This label name will serve as the default file name during export.
    • Repeat this process for all sections you want to extract.
  2. Open the Export Multiple Dialog:
    • In the top menu, navigate to File > Export > Export Multiple... (or press Ctrl + Shift + L / Cmd + Shift + L).
  3. Configure Export Settings:
    • Export Format: Choose your desired file format (e.g., WAV, MP3, FLAC) and configure the audio quality options.
    • Export Location: Choose the folder on your computer where the finished files should be saved.
    • Split Files Based On: Select the Labels option.
    • Name Files: Choose Using Label/Track Name to automatically name each exported file according to the text inside its corresponding label.
  4. Run the Export:
    • Click the Export button.
    • If the metadata editor appears, you can review or modify the tags for each segment, or click OK to proceed through each file.
    • Audacity will process each region label sequentially and display a confirmation screen listing all exported audio files upon completion.
