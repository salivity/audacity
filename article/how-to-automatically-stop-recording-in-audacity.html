How to Automatically Stop Recording in Audacity

Audacity allows users to automatically stop recording after reaching a specific time limit using its built-in Timer Record feature. This article explains how to configure this setting to schedule unattended recordings, define precise recording durations, and automatically save or export your audio files when the recording concludes.

How to Use Timer Record in Audacity

Audacity provides a dedicated tool called Timer Record that lets you schedule both the start and stop times, or simply set a specific duration for your recording.

Follow these steps to set a time limit:

  1. Open Audacity on your computer.
  2. Go to the top menu bar and select Transport.
  3. Hover over Recording, then click Timer Record... (You can also press Shift + T on your keyboard as a shortcut).
  4. The Timer Record window will appear with several timing controls:
    • Start Date and Time: Set this to the current time to start immediately, or set a future time if you want Audacity to begin recording automatically later.
    • End Date and Time: Specify the exact time the recording should conclude.
    • Duration: Alternatively, simply enter how long you want the recording to last in hours, minutes, and seconds (e.g., 01:00:00 for one hour). Adjusting the duration automatically updates the end time.

Post-Recording Actions

Beneath the time settings, the Timer Record dialog provides Automatic Save / Export and Automatic Action options to manage what happens after the time limit is reached:

  • Save Project: Automatically saves the Audacity project upon completion.
  • Export Audio: Automatically exports the recorded audio to your preferred format (such as WAV or MP3) and file path without requiring manual input.
  • Do Nothing / Shutdown: Choose whether the software should do nothing, close the program, or shut down your computer once the recording stops.

Starting the Session

Once your time limit and post-recording preferences are configured, click OK. The recording will either begin immediately or wait for the scheduled start time. When the designated duration expires, Audacity will automatically stop recording and execute any specified post-recording actions.
